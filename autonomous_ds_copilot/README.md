# Autonomous Data Science Co-Pilot

An AI-powered agent for data analysis that accepts CSV, Excel, or JSON files, automatically discovers patterns, and generates professional charts and insights. It writes and executes Python/Pandas code on its own, uses a local RAG (Retrieval-Augmented Generation) pipeline over Python & Pandas documentation to recover from execution errors, and self-heals in a background sandbox until a valid output is delivered.

---

## 🌟 Key Features

1. **Autonomous Code Generation:** The AI agent analyzes your data's schema and structure, and writes a tailored Python/Pandas script to answer your query.
2. **Subprocess Sandbox Execution:** Generated code is executed in an isolated, headless background subprocess with custom timeouts to protect your system.
3. **RAG Error Correction:** If an execution error occurs (e.g., a `KeyError`, `ValueError`, or deprecated syntax), the agent uses a pure-Python TF-IDF search engine to query official troubleshooting documentation.
4. **Self-Healing Loop:** The agent appends the retrieved error-resolution documents to its context and automatically rewrites, re-executes, and validates the script up to 3 times.
5. **Interactive UI:** Built using Streamlit, featuring a premium dark mode, glassmorphism elements, live execution logs showing the agent's "thinking" process, and rendering of tabular data, static charts, or interactive Plotly maps.

## ⚙️ Setup and Installation

### 1. Prerequisites
Ensure you have **Python 3.10+** installed on your system.

### 2. Install Dependencies
Open your terminal inside the project directory and run:
```bash
pip install -r requirements.txt
```

### 3. Generate Sample Data
Run the following script to generate the 5 demonstration datasets inside the `sample_data/` directory:
```bash
python generate_sample_data.py
```

### 4. Set Up API Keys
You will need an API key for one of the following providers:
- **Gemini API** (Google)
- **OpenAI API**
- **Anthropic API** (Claude)

You can configure your key by creating a `.env` file in the project root:
```env
GEMINI_API_KEY=your_gemini_key_here
# OR
OPENAI_API_KEY=your_openai_key_here
# OR
ANTHROPIC_API_KEY=your_anthropic_key_here
```
*Alternatively, you can input your API key directly into the Streamlit sidebar.*

---

## 🚀 Running the Web Application

Launch the Streamlit app by executing:
```bash
streamlit run app.py
```

Once running, open the URL (usually `http://localhost:8501`) in your browser to interact with the Co-Pilot.

## 📊 End-to-End Use Cases

Try these 5 use cases with the pre-generated datasets in `sample_data/`:

1. **Sales Dashboard (sales_data.csv):**
   * *Query:* "Create a bar chart showing the total revenue generated by each region."
2. **Data Quality Audit (dirty_data.csv):**
   * *Query:* "Identify duplicate rows, clean the bad salary values, handle missing ages by filling with the mean, and write a summary."
3. **Trend Analysis (traffic_data.json):**
   * *Query:* "Is my traffic growing? Create a line chart showing daily Visitors and PageViews over time."
4. **Cohort Analysis (customer_segments.csv):**
   * *Query:* "Segment customers by Spending Score vs Annual Income. Generate a scatter plot showing these groups."
5. **Ad-hoc Queries (ad_hoc_queries.xlsx):**
   * *Query:* "Compare the budgets and actual spent for each department from the Budgets and Expenses sheets. Draw a grouped bar chart."
